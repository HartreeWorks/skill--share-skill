# Share Skill

A Claude Code skill for converting private skills into public GitHub repositories, making them shareable with the community.

## Documentation

See [SKILL.md](./SKILL.md) for complete documentation and usage instructions.

## Installation

```bash
# Run install
npx skills add HartreeWorks/skill--share-skill

# When asked "Which agents do you want to install to?", select "Claude Code" in addition to the default "Universal" list.
```

If you get "command not found", [install Node](https://github.com/HartreeWorks/skills/blob/main/how-to-install-node.md) then try again.
